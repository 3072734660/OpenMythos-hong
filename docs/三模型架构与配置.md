# 三模型架构与配置

本项目的三档模型遵循同一使用合同：同一任务格式、同一训练入口、同一服务入口，仅模型大小、设备与量化方式不同。

## 配置文件

### tiny

```text
configs/family_tiny_moe_quant.yaml
```

用于快速验证流程。tiny 使用项目内真实 MoE 结构，包含 router、top-k routing 和多个 experts。它适合调试，不适合承担真实泛化能力。

### 本地 CUDA 小 MoE

```text
configs/family_small_moe_3050ti_4g.yaml
configs/family_small_moe_3050ti_4g_8bit_offload.yaml
```

默认使用 OLMoE 1B-active / 7B-total 公开 MoE。4GB 显存下建议优先尝试 4-bit NF4；如果环境不支持或 OOM，再切换到 8-bit CPU offload。

### 集群 MoE

```text
configs/family_cluster_moe_smaller_than_oss20b.yaml
```

默认使用 Qwen1.5-MoE-A2.7B。适合多卡或集群微调。

## 统一任务格式

推荐数据为 JSONL：

```json
{"prompt":"用户输入...","response":"模型应该输出的内容..."}
```

多轮格式：

```json
{"messages":[{"role":"system","content":"..."},{"role":"user","content":"..."}],"response":"..."}
```

训练入口会尽量只对 response 部分计算 loss，避免模型学习复述 prompt。

## 公开模型与本地路径

公开模型需要下载到 `models/` 后离线运行。例如：

```text
models/OLMoE-1B-7B-0125
models/Qwen1.5-MoE-A2.7B
```

配置中的 `local_model_dir` 应指向这些本地目录。
