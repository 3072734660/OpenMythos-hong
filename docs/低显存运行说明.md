# 低显存运行说明

本地 CUDA 小 MoE 档面向 3050Ti 4GB 级别设备。4GB 显存无法承受常规 fp16 全参数训练，因此必须使用低显存策略。

## 推荐策略

1. 4-bit NF4 量化加载。
2. LoRA/QLoRA 微调，不做全参数训练。
3. batch size 设置为 1。
4. 使用短上下文，例如 192 或 256。
5. 启用 gradient checkpointing。
6. 必要时使用 CPU/disk offload。
7. 训练数据按短样本课程组织，不要一开始使用超长输出。

## 预检

```bash
python scripts/check_3050ti_4g_ready.py \
  --config configs/family_small_moe_3050ti_4g.yaml \
  --require-cuda \
  --require-weights
```

如果 4-bit 路径失败，可以切换：

```text
configs/family_small_moe_3050ti_4g_8bit_offload.yaml
```

## 注意

4GB 显存可以做低显存微调和推理测试，但速度会较慢。不要期待它完成大规模全参数训练。
